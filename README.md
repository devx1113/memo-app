# Memo Reminder

A Windows app for dated memos that keeps reminding you on the day until you dismiss the reminder.
The interface is available in **English** and **Japanese** (Settings → Appearance & behavior → Language).

## Getting started

### The .exe (recommended)
Double-click `MemoReminder.exe`. You don't need Python or an installer.
Put it in a permanent folder first, then turn on Settings → **Start automatically with Windows**
so it keeps running in the background.

Windows SmartScreen may warn about an unsigned app the first time; choose **More info → Run anyway**.

### Building the .exe yourself
On Windows, install [Python 3.12](https://www.python.org/downloads/windows/) (tick "Add python.exe to PATH"),
then double-click `build_exe.bat`. The result is `dist\MemoReminder.exe`.
If the project is on GitHub, the "Build Windows exe" Actions workflow builds it too.

### Running from source
`setup.bat` → `run.bat` (or double-click `main.pyw`).

## How reminders work (default settings)

Example: a memo for Nov 17, 10:00–11:00 "Team meeting"

| Time | What happens |
|---|---|
| Nov 17 07:00 | A reminder card appears at the bottom right |
| 07:05 | It hides automatically |
| 07:10 | It shows again (5 min on, 5 min off, until you dismiss it) |
| 09:45 | It switches to an orange "Starting soon · in 15 min" alert |
| 10:00 | The event starts, so reminders stop |

Reminder buttons

- **Got it / ×** — stop reminding me today
- **In 10 min / ▾** — snooze for the chosen time
- **Mark done** — complete the memo and stop its reminders
- **Click the title** — open the memo

If the PC was off at 07:00 (e.g. you turn it on at 09:00), the reminder appears as soon as the app starts.

## Settings (Settings button)

| Tab | Setting | Default |
|---|---|---|
| Reminders | Start reminding at | 07:00 |
| | Days in advance | 0 (on the day only) |
| | Show for (0 = until closed) | 5 min |
| | Repeat every | 5 min |
| | Default snooze / snooze options | 10 min / 5,10,15,30,60 |
| | "Starting soon" alert / minutes before | on / 15 min |
| | Keep reminding (until start / until end / until midnight) | until the event starts |
| Popup & sound | Position, width, opacity, border flash | bottom right |
| | Also send a Windows notification (Action Center) | off |
| | Sound on/off, system sound, custom WAV file | on |
| Appearance & behavior | Language (English / 日本語) | English |
| | Theme (match Windows / light / dark), font, text size, week start, "Upcoming" days | match Windows |
| | Close to tray, start hidden, start with Windows | |

Each memo's **Notifications** tab can override the start time, days in advance, show time,
repeat interval, "starting soon" alert and sound for that memo only (untick "Default").

## Other features

- Windows 11 style (light/dark theme, dark title bar, rounded reminder cards)
- Calendar shows memo titles, colored by priority; completed memos are struck through
- Repeating memos: daily / weekdays / weekly / monthly / yearly, with an optional end date
- Priorities: high (red), medium (blue), low (green)
- "Days in advance": e.g. 2 reminds you two days before, the day before and on the day
- Pause all reminders for 30 min / 1 h / 3 h / until resumed (Notifications menu or tray)
- Upcoming list, search, done tracking, duplicate
- Export / import (JSON) for backups or moving to another PC
- Runs once only (launching it again brings the existing window to the front)
- Keyboard: Ctrl+N new · Ctrl+F search · Ctrl+T today · ↑↓ select · Enter edit · Space done · Delete remove

## Where your data is stored

`%APPDATA%\MemoReminder\`

- `memos.json` — your memos (a backup `memos.json.bak` is kept on every save)
- `settings.json` — settings
